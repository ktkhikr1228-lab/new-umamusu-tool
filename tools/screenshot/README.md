# スクショ半自動化ツール

トレーナーガイドのスクショを「ホットキー1発でキャプチャ→保存→ラズパイ転送」するツール。
ゲームへの入力は一切自動化しない(タブ切り替え・スクロールは人間が行う)。

## 準備(初回のみ)

1. AutoHotkey v2 をインストール: https://www.autohotkey.com/
2. uma-piへの鍵認証を設定(パスワードなしでssh/scpできる状態にする):

   ```powershell
   ssh-keygen -t ed25519          # 既に鍵があればスキップ
   type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh katao@uma-pi "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
   ```

イベント名は起動のたびに聞かれるので、`current_event.txt` を手で書き換える必要はない。

## 使い方

1. `uma_capture_hotkeys.ahk` をダブルクリックする
2. **イベント名の確認**が出る。前回の名前が入っているので、
   - 今回もその名前でよければそのまま OK
   - 違うときは書き直して OK(例: `2026-11_CM`。半角の英数字・ハイフン・アンダーバーだけ)
   - キャンセルを押すとツールは起動せず終了する

   書き直した名前は `current_event.txt` に保存され、次回はそれが最初に出る。
3. タスクトレイに常駐し、画面右上に今の状態がずっと表示される:

   ```
   イベント: 2026-11_CM
   逃げ / 超おすすめ (1/8)
   この枠: ★まだ 0枚★
   F8 撮影 / F9 次へ / Shift+F9 戻る
   ```

   - 「この枠」は、今の脚質・区分でこのPCに保存済みの枚数。撮り忘れた枠は「★まだ 0枚★」のままなので気づける
   - ラズパイへ送れていない画像があるときだけ「未送信: ○枚」の行が増える
4. ゲームの画面を手前にして、下のキーで撮っていく

### キー

| キー | 動作 | 効く場所 |
| --- | --- | --- |
| F8 | 今の枠で撮影(キャプチャ→保存→転送) | ゲームの画面が手前のときだけ |
| F9 | 次の枠へ進む | ゲームの画面が手前のときだけ |
| Shift+F9 | ひとつ前の枠へ戻る | ゲームの画面が手前のときだけ |
| Ctrl+Alt+1 | 脚質を「逃げ」に | どこでも |
| Ctrl+Alt+2 | 脚質を「先行」に | どこでも |
| Ctrl+Alt+3 | 脚質を「差し」に | どこでも |
| Ctrl+Alt+4 | 脚質を「追込」に | どこでも |
| Ctrl+Alt+5 | 区分を「超おすすめ」に | どこでも |
| Ctrl+Alt+6 | 区分を「おすすめ」に | どこでも |
| Ctrl+Alt+0 | 常駐終了 | どこでも |

- F8 と F9 は、ブラウザやメモ帳などほかのアプリを使っているときはツールが横取りしない(そのアプリ本来のF8/F9として働く)
- F9 が進む順番は固定:

  逃げ/超おすすめ → 逃げ/おすすめ → 先行/超おすすめ → 先行/おすすめ → 差し/超おすすめ → 差し/おすすめ → 追込/超おすすめ → 追込/おすすめ

- 最後(追込/おすすめ)で F9 を押すと、下がっていく3音と「ここが最後の枠です」が出て止まる。最初には戻らない
- Ctrl+Alt+1〜6 で直接切り替えても、F9 はその場所の続きから進む
- F9 で進むとき、直前の枠が0枚だと「さっきの枠は 0枚でした」と知らせる

### 流れの例

逃げタブを開く → F8(スクロールしながら超おすすめ部分を撮る) → F9 → F8(おすすめ部分) → F9 → ゲームで先行タブへ → F8 → … → 追込/おすすめを撮り終えたら完了。

F9 はツール側の枠を切り替えるだけ。**ゲームのタブ切り替えとスクロールは自分で行う。**

## 音の意味

| 音 | 意味 |
| --- | --- |
| 高いピッ(1回) | 撮影してこのPCに保存できた |
| さらに高いピッ | ラズパイへ転送できた(1枚ごとに1回。4枚以上まとめて送ったときは長めに1回) |
| 低いブー(長め) | 転送できなかった(このPCには保存済み。あとで自動で再送される)。または、ゲームの画面が見つからないなどの失敗 |
| 中くらいのブブッ(2回) | 同じ画面だった(保存していない) |
| 短いピ | 枠を切り替えた(F9、Shift+F9、Ctrl+Alt+1〜6) |
| 下がっていく3音 | F9 で最後の枠まで来た |
| 低い音1回 | Shift+F9 で最初の枠より前には戻れない |

ふつうに撮れたときは「高いピッ → 少しして、さらに高いピッ」の2回が聞こえる。
続けて速く撮ったときは、転送の音がまとまって少し遅れて鳴ることがある。

## 同じ画面を撮ってしまったとき

スクロールを忘れて、同じ枠の直前の1枚とまったく同じ画面で F8 を押すと、

- 保存も転送もしない
- 「ブブッ」と2回鳴り、右上に「同じ画面です(保存していません)」と出る

スクロールしてからもう一度 F8 を押せばよい。
比べる相手は「同じイベント・同じ脚質・同じ区分のフォルダにある、いちばん新しい1枚」だけ。
1ドットでも違えば別の画面として保存する(画面のどこかが動いている場面では警告は出ない)。

## 転送に失敗したとき(自動で再送)

- 撮影した画像は、転送の成否に関係なく必ずこのPCに保存される
- 転送は撮影とは別に裏で行うので、通信が遅い・切れているときでも次の F8 は待たされない
- 送れなかった画像は `%USERPROFILE%\uma-shots\pending_uploads.txt` に1行ずつ記録され、右上に「未送信: ○枚」と出る
- 次のタイミングで、記録されている画像をまとめて自動で送り直す:
  - 次に F8 で撮影したとき
  - ツールを起動したとき
- 送れた分から記録が消え、全部送れると「未送信」の行が消える
- `pending_uploads.txt` は手で編集しなくてよい。再送をあきらめたいときだけ、このファイルを消す
- 手で今すぐ再送したいとき(PowerShellで):

  ```powershell
  powershell -ExecutionPolicy Bypass -File capture_upload.ps1 -ResendOnly
  ```

## 撮り方

- 「超おすすめ」と「おすすめ」の境界を1枚で撮る必要はない
- それぞれの区分に切り替えてから、該当する範囲だけをF8で撮る
- 画面に見出しが無くても、現在の区分はホットキーで指定済みなので推測しない
- 撮り直すときは、そのイベントの該当脚質・区分フォルダだけを最初から撮り直す
- イベント名を途中で変えたいときは、Ctrl+Alt+0 で終了して起動し直す

## 保存先

- ローカル: `%USERPROFILE%\uma-shots\<イベント>\<脚質>\<区分>\`
- ラズパイ: `/home/katao/uma-guide-data/screenshots/inbox/<イベント>/<脚質>/<区分>/`
  (アップロードGUIと同じinbox構造なので、そのままGemini抽出に回せる)
- 脚質フォルダは `1_nige` `2_senkou` `3_sashi` `4_oikomi`、区分フォルダは `super` `recommended`(この形は変えない)

## 転送後の流れ

ラズパイで抽出(またはアップロードGUI http://uma-pi:8080 から実行):

```bash
cd /home/katao/uma-tool-automation
python3 gemini_extract_uploaded.py --event 2026-07_CM --race "中山 芝 3600m" --strategy senkou
```

抽出はskill_master照合で表記ゆれを自動修正し、怪しい名前には `unknown_skill:要確認` が付く。

## Windowsでの動作確認

ツールを変更したあとは、次の順に確かめる。イベント名は練習用に `test_check` などを使うと、本番のフォルダを汚さない
(終わったらPCの `uma-shots\test_check` と、ラズパイの `inbox/test_check` を消す)。

### 1. 起動時のイベント名確認

1. `uma_capture_hotkeys.ahk` をダブルクリック → 「イベント名の確認」が出て、前回の名前が入っている
2. `だめ な名前!` と入れて OK → 「使えない文字があります」と出て、もう一度入力に戻る
3. `test_check` と入れて OK → 右上の表示の1行目が「イベント: test_check」になる
4. `current_event.txt` をメモ帳で開く → `test_check` に変わっている
5. Ctrl+Alt+0 で終了し、もう一度起動 → 最初から `test_check` が入っている。キャンセルを押す → 「終了します」と出てツールが起動しない(トレイにアイコンが残らない)
6. もう一度起動して `test_check` のまま OK

### 2. F8/F9 がゲームのときだけ効くこと

1. メモ帳やブラウザを手前にして F8、F9 を押す → 音が鳴らず、右上の表示も変わらない(ブラウザなら F9 は何も起きず、Excel等ではそのアプリ本来の動きをする)
2. ゲームの画面をクリックして手前にし、F8 → 高いピッが鳴る
3. ほかのアプリを手前にしたまま Ctrl+Alt+2 → 右上が「先行」に変わる(Ctrl+Alt はどこでも効く)。Ctrl+Alt+1 で「逃げ」に戻す

### 3. F9(次へ)と表示

1. 右上が「逃げ / 超おすすめ (1/8)」の状態で、ゲームを手前にして F9 を7回押す → 押すたびに短いピが鳴り、(2/8)…(8/8) と順に進む。脚質が変わるときは「ゲームの脚質タブも切り替えてください」と出る
2. (8/8) 追込/おすすめ でもう一度 F9 → 下がっていく3音と「ここが最後の枠です」。表示は (8/8) のまま
3. Shift+F9 → (7/8) に戻る。(1/8) まで戻してさらに Shift+F9 → 低い音と「ここが最初の枠です」
4. Ctrl+Alt+3 → 「差し / 超おすすめ (5/8)」になる。F9 → 「差し / おすすめ (6/8)」に進む(Ctrl+Alt と F9 がずれない)
5. まだ撮っていない枠では「この枠: ★まだ 0枚★」、F8 で撮ると数秒以内に「この枠: 1枚」に変わる

### 4. 同じ画面の警告

1. ゲームでトレーナーガイドの動きのない画面を出し、F8 → 高いピッ(保存)
2. スクロールせずにもう一度 F8 → 「ブブッ」と2回鳴り、「同じ画面です(保存していません)」と出る。「この枠」の枚数は増えない
3. 少しスクロールして F8 → 高いピッが鳴り、枚数が1増える
4. `uma-shots\test_check\…` のフォルダを開き、同じ画像が2枚できていないことを見る

### 5. 転送と自動再送

1. ふつうの状態で F8 → 高いピッのあと、少ししてさらに高いピッ。ラズパイの `inbox/test_check/<脚質>/<区分>/` に画像がある
2. PCのネットワークを切る(Wi-Fiオフ、またはTailscaleを切る)
3. スクロールしながら F8 を2〜3回、間を空けずに押す → 毎回すぐ高いピッ(保存)が鳴り、待たされない。10秒ほどして低いブー。右上に「未送信: ○枚」が出る
4. PCの `uma-shots\pending_uploads.txt` を開く → 送れなかった画像が1行ずつ書かれている
5. ネットワークを戻し、スクロールして F8 → 新しい1枚と一緒にたまっていた分も送られ、さらに高いピッが鳴り、数秒で「未送信」の行が消える
6. もう一度ネットワークを切って F8 で1枚撮り、Ctrl+Alt+0 で終了。ネットワークを戻してツールを起動 → 起動しただけで再送され、「未送信」が消える
7. ラズパイ側で、撮った枚数と同じ数の画像が届いていることを確かめる

### うまくいかないとき

- 起動時に文字化けする・エラーが出る: `uma_capture_hotkeys.ahk` が「UTF-8(BOM付き)」で保存されているか確かめる。AutoHotkey が v2 かも確かめる
- F8 を押しても何も起きない: ゲームの画面が手前にあるか、ゲームのウィンドウ名が `UmamusumePrettyDerby_Jpn` のままかを確かめる
- 音や表示の様子を詳しく見たい: PowerShell を開いて `powershell -ExecutionPolicy Bypass -File capture_upload.ps1 -Strategy nige -Event test_check` を直接実行すると、英語でメッセージが出る
